cnn_uvm UVM 구조도

agent / coverage / env / interface / package / monitor / item / sequence / sequencer / test / scoreboard / driver / tb_top 을 파일 하나씩으로 나눈 구조에, CNN 가속기 검증에 필요한 predictor(레퍼런스 모델) · RAM responder · layer checker · SVA 를 더한 형태입니다. 소스 위치는 cnn_uvm/tb/ 입니다.

추론 1 회의 흐름

  1. test 가 virtual sequence 를 env.vsqr 에 시작한다.
  2. sequence 가 cnn_infer_item 을 만들어 (패턴 선택) pack_to_mem() 으로 img_mem / ram_mem 에 DUT 배치대로 쓴다.
  3. cnn_csr_item(OP_START) 을 csr_sqr 로 보내면 driver 가 start 핸드셰이크를 하고 done_status 를 기다린다.
  4. DUT 가 RAM 주소를 내면 responder 가 다음 clk 에 RAM 모델 내용을 돌려준다 (동기 RAM 타이밍).
  5. csr_mon 이 START 를 내면 predictor 가 RAM 모델을 unpack_from_mem() 하고 cnn_ref_model 로 golden 을 만든다.
  6. cnn_state 가 C_LAYER_END 를 벗어날 때마다 layer checker 가 input_buf 를 probe 로 읽어 레이어 0 / 1 / 2 결과를 비교한다.
  7. DONE 에서 scoreboard 가 o_final_result 와 golden 을 비교하고 coverage 가 sample 한다. SVA 는 내내 핸드셰이크 규칙을 본다.
